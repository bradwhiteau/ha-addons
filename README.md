# Brad's Home Assistant apps

Add this repository in Home Assistant: **Settings › Add-ons › Add-on store › ⋮ › Repositories**, then paste the repository URL.

- **Email Triage** (`email_triage/`): triages new Gmail with Claude. See `email_triage/DOCS.md`.

No secrets live in this repository. All keys are entered in the add-on's Configuration tab in Home Assistant.
